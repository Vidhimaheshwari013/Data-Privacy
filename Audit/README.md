# 🔐 Data Privacy Audit of Swiggy

## 📌 About the Project

This project presents a **Data Privacy Audit of Swiggy** based on publicly available information from Swiggy's official privacy and security-related documents.

The objective is to understand how Swiggy **collects, uses, shares, stores, and protects user data**, and to identify potential privacy risks.

## 🎯 Objectives

* Analyze the types of personal and technical data collected.
* Examine how user data is used and shared.
* Review data storage and security practices.
* Understand available user privacy controls and rights.
* Identify potential privacy risks and provide recommendations.

## 🔍 Audit Areas

| Area                       | Focus                                            |
| -------------------------- | ------------------------------------------------ |
| 📥 Data Collection         | Personal, device, usage and location information |
| 🔄 Data Usage & Sharing    | Service providers, advertising and other parties |
| 🔒 Data Storage & Security | Security measures and cloud infrastructure       |
| 👤 User Rights & Control   | Deletion, withdrawal and privacy choices         |
| ⚠️ Potential Risks         | Privacy and unauthorized-access risks            |

## ⚠️ Key Findings

The audit identified the following areas that require continued attention:

* Collection of extensive device and usage information
* Location privacy considerations
* Sharing of data with third-party service providers
* Use of third-party cloud infrastructure
* Risk of unauthorized access or data breaches
* Transparency around data retention and user controls

These are **potential risks identified for academic analysis** and do not represent claims that Swiggy currently has an actual security vulnerability or has experienced a data breach.

## 💡 Recommendations

* Follow the principle of **data minimization**.
* Provide clear explanations of why different types of data are collected.
* Give users transparent and accessible privacy controls.
* Maintain strong encryption and access-control mechanisms.
* Regularly monitor systems for unauthorized access.
* Clearly communicate third-party data-sharing and cloud-storage practices.

## 🧪 Methodology

The audit follows:

**Practice → Evidence → Potential Risk → Risk Level → Recommendation**

The analysis is based on publicly available Swiggy documents.

## 🔐 Ethical Scope

This project is strictly based on **publicly available information**.

No unauthorized access, penetration testing, private account access, or collection of private user information was performed.
